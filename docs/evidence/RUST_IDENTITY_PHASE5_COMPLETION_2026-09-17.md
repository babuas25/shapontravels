## Operational boundaries

- Rust remains disabled by default; staged identity is still not production authority. Next remains isolated `rust-preview` only, with production/remote preview rejected.
- Asset transport additionally requires `SHAPON_IDENTITY_ASSET_MODE=test` and a disposable Cloudinary cloud name ending `identity-test` or `identity_test`. Its configuration must preserve original format/byte size and the SHA-256 context used for receipt verification. The example is disabled; real `.env` files were not edited. Tests use an injected Cloudinary double and perform no actual storage operation.
- Upload/start is one shot. A crash, timeout or mismatched receipt is not permission to resend. Provider-read recovery may finish only an exact matching reserved asset while original authority/versions still hold. A missing object is not proof of no delayed upload. Stale/orphaned private objects remain retained for operational review.
- Document removal/replacement updates the current reference and retains version/history; it does **not** physically destroy retained Cloudinary evidence. Private download links use the existing short expiry; already issued links do not become instantly revocable. The logo is public-facing branding, delivered through the existing authenticated image URL helper.
- Clerk's current user-name update does not atomically attach a request-correlation marker. Equal names after an ambiguous write cannot prove the request finished; those effects remain `needs_reconciliation` for support review and block blind resend. This matches the conservative unknown-outcome policy; the app's saved Rust display name remains authoritative. No unsupported force-success endpoint was added.
- Profile/document requests retain the 4096-byte bridge bound. Application submission alone allows 32768 bytes for all required bounded Unicode fields; image bytes never enter Rust JSON. Next multipart input is bounded before form parsing.
- Business integration, existing screen wiring, full deployment acceptance and controlled activation remain **Phases 6–9**. Do not lift those gates based on this evidence.
